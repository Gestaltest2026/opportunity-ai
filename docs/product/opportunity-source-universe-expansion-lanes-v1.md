# Opportunity Source Universe Expansion Lanes v1

## Core correction

The strict eligibility gate exposed a product truth: User #1 does not merely need stricter eligibility logic. User #1 also needs a much larger Opportunity Source Universe.

A tiny source universe forces the system into bad behavior:

1. over-rank the few known candidates;
2. overuse expired or membership-blocked sources;
3. confuse `NEEDS_VERIFICATION` with real opportunity;
4. ask ChatGPT to improvise three candidates from a thin pie.

The fix is not web-wide autonomous crawling. The fix is structured source-universe expansion.

## Product role

The Opportunity Source Universe is the market-side memory of Opportunity AI.

It should answer:

- where to search;
- which source classes matter;
- how many sources each lane needs;
- which lanes are underseeded;
- which lanes are official enough to support action;
- which lanes are only pattern-learning or aggregator discovery.

It does not answer whether User #1 can apply. Eligibility remains downstream.

## New target

The previous v0 target of 50 sources was enough for a prototype. It is not enough for reliable scholarship action.

This PR defines:

| Level | Goal |
| --- | ---: |
| Current curated source count | 50 |
| Phase 1 expanded source goal | 150 |
| Full User #1 source universe goal | 300 |

The 150-source goal is not meant to be filled with random links. It is meant to be filled across defined source lanes.

## Expansion lanes

The initial User #1 expansion plan defines ten lanes:

1. `legal-paralegal-professional-bodies`
2. `law-firm-scholarship-programs`
3. `women-adult-returning-learners`
4. `southwest-florida-local-civic`
5. `certification-exam-and-cle-funding`
6. `university-independent-national-databases`
7. `florida-state-and-public-aid`
8. `employer-and-workforce-development`
9. `fgcu-uf-and-institutional-backstop`
10. `pattern-archives-and-expired-pages`

The highest-priority correction is to expand the legal/paralegal professional-body lane and the women/adult-returning-learner lane before asking the system for three application-ready opportunities.

## Important separation

Source expansion is not eligibility.

```text
Source universe expansion
→ candidate discovery
→ official source verification
→ strict eligibility gate
→ inquiry or application packet
→ action ledger
```

This is the correct order.

The wrong order is:

```text
small source universe
→ ask LLM for three scholarships
→ hope eligibility works
```

## Guardrail

The system must be able to say:

```text
We do not have enough source coverage yet.
Expand the source universe first.
```

That is better than giving three weak candidates.
